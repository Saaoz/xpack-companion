# Security policy

*Français plus bas.*

If you find a vulnerability in the mod (for example a way to leak a player's link token, to send progress in someone else's name, or to read files the mod should not read), **do not open a public issue**.

Report it privately through GitHub: **Security** tab → **Report a vulnerability**. Include the mod version, loader, Minecraft version and the steps to reproduce.

You will get an answer as soon as possible. Please give us reasonable time to fix the issue before disclosing it.

Only the latest released version of the mod receives security fixes.

---

# Politique de sécurité

Si tu trouves une faille dans le mod (par exemple un moyen de faire fuiter le jeton de liaison d'un joueur, d'envoyer des progrès au nom de quelqu'un d'autre ou de lire des fichiers que le mod ne devrait pas lire), **n'ouvre pas d'issue publique**.

Signale-la en privé sur GitHub : onglet **Security** → **Report a vulnerability**. Indique la version du mod, le loader, la version de Minecraft et comment reproduire le problème.

Tu auras une réponse dès que possible. Laisse-nous le temps de corriger avant de rendre la faille publique.

Seule la dernière version publiée du mod reçoit les correctifs de sécurité.
